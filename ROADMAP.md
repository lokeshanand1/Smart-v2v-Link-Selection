# Project Roadmap

The vision for the Smart V2V Link Selection project includes the following planned enhancements:

## Phase 1: Optimization & Intelligence
- [ ] **Reinforcement Learning Integration:** Implement a DRL agent (e.g., PPO or DDPG) for real-time link switching based on reward maximization.
- [ ] **Dynamic Weight Optimization:** Use meta-heuristic algorithms (e.g., Particle Swarm Optimization) to fine-tune utility weights during runtime.

## Phase 2: Real-World Readiness
- [ ] **Real-World Datasets:** Integrate field-test data from actual V2X communication testbeds.
- [ ] **Edge Deployment:** Optimize models for deployment on NVIDIA Jetson or similar edge devices for in-vehicle use.

## Phase 3: Next-Gen Integration
- [ ] **6G V2X Integration:** Incorporate Terahertz (THz) and mmWave communication models.
- [ ] **IoT & Smart City Integration:** Expand the model to include Vehicle-to-Infrastructure (V2I) and Smart Grid coordination.
- [ ] **Privacy & Security:** Implement Federated Learning to ensure vehicle data privacy during model updates.
