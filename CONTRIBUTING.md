# Contributing to Smart V2V Link Selection

First off, thank you for considering contributing to this project!

## How to Contribute

### Raising Issues
- Check if the issue has already been reported.
- Provide a clear and descriptive title.
- Include as much detail as possible: steps to reproduce, environment info, and expected behavior.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Ensure your code follows the established coding guidelines.
4. Update documentation if necessary.
5. Submit a pull request with a detailed description of your changes.

## Coding Guidelines
- **Python:** Follow PEP 8 style guidelines.
- **Documentation:** Use clear, concise language in Docstrings and Markdown files.
- **Modularity:** Keep functions focused and components decoupled.
- **Research Integrity:** Do not modify core physical layer formulas without extensive validation.
